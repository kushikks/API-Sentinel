# Developer A security

Identity hashes passwords with BCrypt cost 12. Registration accepts 12 or more characters and at most 72 UTF-8 bytes. Self-registration grants either `API_OWNER` or `CONSUMER`. An authorized Identity database operator can assign `ADMIN` to a known UUID through `user_roles`. A refreshed or newly issued token carries the current role grants.

Identity signs RS256 tokens with a 3072-bit RSA key in the local environment. Resource services validate the signature, issuer, audience, expiry and UUID subject. A JWT is issued for ten minutes and remains valid within its configured clock-skew allowance. A seven-day refresh family uses a high-entropy opaque cookie and stores only SHA-256 digests. Refresh rotates the token. Reuse revokes the family and writes an audit entry. Logout revokes the family and clears the cookie. Existing access tokens expire on their normal schedule. The browser keeps the access token in memory and refreshes through a Secure, HttpOnly, SameSite=Strict cookie in deployment. Cookie-based session endpoints require `X-Sentinel-CSRF: 1` and CORS enforces an explicit allowlist.

API owner or admin roles are required for Registry writes. Public Registry and Analyzer reads require the owner or an admin. The consumer role provides a signed-in account for future Developer B consumer workflows. The Registry records the API owner UUID with the submission so Analyzer can enforce ownership while Registry is unavailable.

Internal service credentials use `X-Sentinel-Service-Key` on the private network. Separate keys authorize Analyzer spec reads, Registry status reads, Impact metadata and finding reads, and Prometheus metrics. The Gateway must route only the documented public paths and keep service keys away from browser requests. Use HTTPS for internet ingress, rate-limit registration, login and large uploads at the Gateway, and restrict Docker network ingress for business services, Actuator, Eureka, PostgreSQL and RabbitMQ.

Registry and Analyzer accept UTF-8 OpenAPI 3.0.x and 3.1.x with a `paths` object. They enforce a 1 MiB raw input limit, 64 levels of nesting and 100,000 parse tokens. Parsing rejects duplicate keys, additional documents, YAML anchors, tags and aliases, and external or missing references. OpenAPI validation uses Swagger Parser with reference resolution disabled. The Registry records base URLs as metadata. It never requests the uploaded server URLs or probes endpoints.

Analyzer bounds reference hops, schema recursion, comparison work, output fields, total findings and maximum concurrent workers. A budget violation fails the affected job with a safe diagnostic. Public errors give status and safe detail. Internal administrative and configuration endpoints are outside the published Gateway routes. SQL values use bound parameters. The isolated schema roles in the standalone setup enforce database ownership.

Migration suggestions run only after an authorized owner or administrator makes an explicit request. Analyzer sends Gemini a bounded selection of finding categories, severities, HTTP methods, route and field paths, and recognized old or new schema types when applicable. It omits raw contracts, arbitrary finding descriptions and values, internal IDs, account details, and client code. Endpoint and field names may still contain sensitive metadata, so enable the provider only for contracts whose metadata may be shared with Google. Analyzer reads the key server-side, sends it to Google's fixed HTTPS endpoint in the authentication header, and uses safe error messages that omit upstream bodies and credentials.
